# referencias

Las maquetas y hojas de recursos que guiaron el diseño, en WebP a 1400 px.

Se guardan comprimidas y no en su PNG original por una razón práctica: los
originales sumaban **38 MB** y eran capturas de pantalla de maquetas, no
recursos que use la aplicación. A este tamaño se siguen leyendo perfectamente
para comparar contra lo construido, y pesan 1,8 MB entre las catorce.

Los originales siguen en el historial de git; nada se perdió.

| Archivo | Qué es |
| --- | --- |
| `poster-16-pantallas.webp` | Las dieciséis pantallas del flujo, versión clara |
| `poster-pantallas-oscuro.webp` | Lo mismo, versión oscura |
| `poster-flujo-operativo.webp` | El recorrido completo del vehículo |
| `maqueta-tablero.webp` | Tablero con saludo, etapas y actividad |
| `maqueta-portada.webp` | Portada de cliente con hero y tres accesos |
| `maqueta-inicio-flota.webp` | Inicio con la flota en fila |
| `maqueta-lujo-overview.webp` | Dirección alternativa, oscura y roja |
| `maqueta-inspeccion-superior.webp` | Inspección con el vehículo visto desde arriba |
| `maqueta-portal-cliente.webp` | Portal público del cliente |
| `maqueta-orden-detalle.webp` | Ficha de orden con checklist y entrega |
| `hoja-recursos-marca.webp` | Paleta, logotipos y fondos de marca |
| `hoja-recursos-fondos.webp` | Fondos y texturas |
| `hoja-recursos-imagenes.webp` | Índice de fotografías |
| `logo-romero-sobre-oscuro.webp` | Logotipo sobre fondo oscuro |

El paquete de fotografías con nombres propios vive en `fotos/`, y lo que la
aplicación usa de verdad está en `public/marca/`, `public/fondos/` y
`public/fotos-de-carros/`.
