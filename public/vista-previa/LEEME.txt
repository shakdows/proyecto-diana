DIANA — VERSION ESTATICA (vista previa navegable)
==================================================

QUE ES ESTO
-----------
Las 25 pantallas del sistema, congeladas como archivos HTML y enlazadas
entre si. Abre index.html con doble clic y navega por todo el menu.

COMO SUBIRLO A VERCEL
---------------------
Opcion A — arrastrar y soltar (lo mas rapido):
  1. Entra a https://vercel.com/new
  2. Arrastra ESTA CARPETA COMPLETA a la pagina
  3. Vercel la publica. No hay que configurar nada.

Opcion B — desde GitHub:
  1. Sube esta carpeta a un repositorio
  2. En Vercel: Add New > Project > elige el repositorio
  3. Framework Preset: "Other".  Output Directory: dejar vacio
  4. Deploy

En las dos, index.html se sirve como pagina de inicio.

QUE ARCHIVO TOCAR PARA CAMBIAR QUE
----------------------------------
  index.html            el tablero de control (la portada)
  ordenes.html          el listado de ordenes
  orden-os-154.html     el detalle de una orden
  estilos.css           COLORES, TIPOGRAFIAS Y BORDES de todo el sitio
  <las demas>.html      una por cada pantalla del menu

Para cambiar un color, busca en estilos.css el bloque ":root" y edita la
variable que toque. Por ejemplo --focus es el azul de la marca.

LO QUE ESTA VERSION **NO** HACE
-------------------------------
Es una FOTOGRAFIA, no el sistema. No tiene:
  - base de datos            - inicio de sesion
  - permisos por usuario     - guardado de nada
  - aislamiento entre empresas

Los datos que se ven son de demostracion y estan escritos dentro del HTML.
Si editas un numero aqui, cambia lo que se ve, pero no cambia el sistema.
